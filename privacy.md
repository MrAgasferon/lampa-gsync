# Политика конфиденциальности Lampa GSync

Lampa GSync (GSync) — плагин для Lampa / ByLampa, который синхронизирует данные приложения между устройствами пользователя через Google Таблицу на его собственном Google Диске.

## Какие данные используются

- **Email Google-аккаунта** — только чтобы показать в настройках плагина, под каким аккаунтом выполнен вход.
- **Доступ к Google Диску (scope `drive.file`)** — только к файлам, созданным самим плагином: таблице «Lampa Sync». Остальные файлы на Диске плагину недоступны.
- **Данные Lampa** (закладки, история и прогресс просмотра, настройки, список плагинов) — записываются в эту таблицу и читаются из неё.

## Где хранятся данные

Все данные хранятся только в таблице на Google Диске пользователя и в локальном хранилище его устройств. У автора плагина нет сервера, и данные пользователей ему не передаются и недоступны.

Токены доступа хранятся только на устройстве пользователя.

## Передача третьим лицам

Данные никому не передаются, не продаются и не используются для рекламы или аналитики.

## Удаление данных

- Выйти из аккаунта в настройках плагина: токен будет отозван, локальные данные синхронизации удалены.
- Отозвать доступ приложения: https://myaccount.google.com/permissions
- Удалить таблицу «Lampa Sync» со своего Google Диска.

## Соответствие требованиям Google

Использование данных, полученных через API Google, соответствует [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включая требования Limited Use.
